# Legacy migration policy

- R-001 — Use the private `nanlogic/saccade-legacy` archive only as a reviewed source.
- R-002 — Migrate one approved component at a time; never copy the legacy tree or revive monolithic classifiers.
- R-003 — Every migrated component records its source commit and path, preserves or replaces its focused tests, and retains truthful limitations.
- R-004 — A migration record proves the bounded provenance of that component; it does not independently promote Catalog or public release status.
- R-005 — Public status still requires the current release candidate's browser and evidence gates.
