# Product and execution boundary

- R-001 — Saccade is a model-independent live semantic Truth Layer for authorized Chrome and Edge tabs.
- R-002 — The production route is Extension → Native Messaging Host → owner-only local IPC → MCP.
- R-003 — Playwright, CDP, screenshots, selectors, and arbitrary coordinates are not product fallback routes.
- R-004 — Unresolved: older contributor guidance says execution is entirely Agent-owned, while current architecture permits Registry-approved object-addressed software click, select, and type through `saccade.act`.
- R-005 — The optional Reference Actuator remains development-only and is not a default product dependency.
