# Saccade 0.1.2 Developer Preview

This release adds a Windows x64 Runtime to the existing Apple Silicon and Intel
macOS setup package. It uses the same Saccade 0.3.24 browser Extension on every
platform.

Windows setup installs the headless Runtime under the current user's local app
data, writes one Native Messaging manifest, and registers it for Chrome and
Edge under `HKCU`. It also adds the local STDIO MCP to detected Codex and Claude
clients. Update, rollback, doctor, uninstall, and purge retain the same bounded
ownership rules as macOS.

The public release requires a Windows Actions build, isolated install and MCP
smoke, real-machine Extension → Native Host → Runtime → MCP evidence, and a
valid Authenticode signature. An unsigned Actions candidate may be used only
for that explicit test and must not be redistributed.

Install after the GitHub Release, npm package, and browser Extension are public:

```sh
npx -y @nanlogic/saccade
```

Saccade remains a semantic Truth Layer. This release does not add Playwright,
CDP, screenshots, arbitrary-coordinate execution, a GUI Runtime, MSI, or the
optional Reference Actuator.
