# Saccade 0.1.3 Developer Preview

Saccade 0.1.3 pairs Runtime 0.1.3 with browser Extension 0.3.25.

This release fixes focus-time authority loss in rich text editors, adds finite
custom drop-surface recognition and bounded file upload, rotates accepted
software-action authority, and completes the Windows file-chooser adapter used
by the same object-addressed upload contract.

The release remains a developer preview. Publish only after the exact
Extension candidate, signed Apple Silicon and Intel macOS Runtime artifacts,
the Windows source-install gate, and independent Claude validation all pass.
