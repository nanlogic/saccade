# Saccade 0.2.0 release gate

Date: 2026-08-30  
Candidate: Extension `0.4.0`, digest
`2d4f7cdcdd04480aa09cab964d7718126a6dcc8667b1629359d709436cad0999`

## Result

The blocking release gate passed on the same Extension candidate in Chrome and
Edge. The public compatibility layer also passed in both browsers.

The verified production route was Extension → loopback Node Broker → MCP. Both
live capability reports returned `runtime:node`, `rust:false`,
`native_host:false`, and exact browser-instance routing.

## Blocking gates

| Gate | Chrome | Edge |
|---|---:|---:|
| Deterministic controls, frames, tables, forms, rich text, and accuracy | passed | passed |
| Object-addressed standard upload with `file_selection_observed` | passed | passed |
| Distinct Agent sessions, cross-read denial, exact inventories, one writer per Tab | passed | passed |

The deterministic suite included:

- same-origin iframe and open-shadow composition, plus truthful restricted-frame coverage;
- semantic table projection;
- independent form batch verification;
- same-origin iframe rich-text replacement with value-free local verification;
- a five-step legacy administration form, separate Save action, and observed Saved state;
- 24/24 ordinary mouse-accuracy targets and 24/24 canvas reflex targets.

The final public-enabled run measured mean exact-target action latency of
8.50 ms for Chrome buttons, 7.47 ms for Chrome canvas targets, 8.48 ms for Edge
buttons, and 7.22 ms for Edge canvas targets.

## Non-blocking public compatibility

Chrome and Edge passed:

- Selenium's official web form;
- DemoQA's React practice form;
- Angular Material select interaction;
- BestBuy homepage Truth readiness;
- NaNMesh, NaNLogic, and Mythcast Era homepage Truth checks.

The two public form reports use `complete:false` because their Submit actions
were deliberately not executed. Field batches and Angular selection were
verified; no external form was submitted.

## Boundaries not certified by this gate

- It does not certify every authenticated Steamworks page or a native-trusted
  upload path. The new legacy-admin fixture proves the reusable control
  mechanisms, not the entire third-party site.
- It does not authorize npm publication or browser-store submission.
- Public compatibility is observational evidence from this candidate run, not a
  permanent claim about third-party pages.
